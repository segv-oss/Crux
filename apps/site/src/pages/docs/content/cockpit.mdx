# The Cockpit

The Cockpit is Crux's core surface: everything a reviewer needs about a pull request, visible in a single glance. No tab-switching, no lost context.

## Three panels, one view

### Left — metadata and context

Author, reviewers, and assignment status; linked Linear tasks and dependencies; branch info, commit count, and deployment targets; recent Slack discussion summaries.

### Center — live code and diff

Syntax-highlighted, interactive diffs with file-level impact analysis. Inline comments and annotations sit next to the code they refer to, with full commit history one click away.

### Right — real-time sync

Live Linear task updates mirrored from your tracker, Slack threads in context, reviewer feedback and approval status, plus CI/CD checkpoints and deployment gates.

## Why it matters

Reviewers stop hunting across three apps to answer "what am I approving?". The context that usually lives in Slack threads, Linear tickets, and PR comments converges on one screen — and stays in sync in real time while the PR evolves.
