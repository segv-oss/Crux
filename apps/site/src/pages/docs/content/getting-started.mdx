# Getting Started

Crux unifies GitHub pull requests, Linear tasks, and Slack discussions into a single, real-time collaboration cockpit. This guide gets you from zero to your first synced PR.

## Prerequisites

- A GitHub organization with API access
- A Linear workspace with an API key
- A Slack workspace where you can install apps
- Node.js 20+ for local development

## Cloud setup

The fastest way to run Crux is the hosted dashboard:

1. Connect your GitHub org via OAuth and select repositories.
2. Paste your Linear API key from Linear settings.
3. Install the Crux Slack app and approve permissions.

Once connected, PRs route through Crux automatically.

## Self-hosting

```bash
git clone https://github.com/segv-oss/crux.git
cd crux
pnpm install
cp .env.example .env
pnpm dev
```

The development server starts at `http://localhost:3000`.

## Configuration

Fill in your `.env` with integration credentials:

```bash
GITHUB_TOKEN=ghp_xxx
GITHUB_WEBHOOK_SECRET=whsec_xxx
LINEAR_API_KEY=lin_xxx
SLACK_BOT_TOKEN=xoxb-xxx
SLACK_SIGNING_SECRET=xxx
DATABASE_URL=postgresql://user:pass@localhost/crux
JWT_SECRET=your_jwt_secret_here
```

## First steps

1. **Connect a repository** — Dashboard → Repositories → Add Repository. Crux auto-configures the webhook.
2. **Create your team** — Dashboard → Team Settings → Add Members. Invite via email or Slack.
3. **Open a test PR** — Push a branch, open a PR on GitHub, and watch the Crux Cockpit populate in real time.

Questions? Open an issue on [GitHub](https://github.com/segv-oss/crux/issues).
